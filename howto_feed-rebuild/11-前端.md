## 对接后端的三个关键点

**1. Vite 代理**（开发期免 CORS）：

```ts
server: { proxy: { '/api': {
    target: 'http://127.0.0.1:8080',
    changeOrigin: true,
    rewrite: p => p.replace(/^\/api/, ''),
}}}
```

**2. token 注入**（`api/client.ts` 封装 fetch/axios）：每个请求带 `Authorization: Bearer <token>`；token 存 localStorage；401 时清 token 跳登录。

**3. Pinia stores**：`auth.ts`（token + accountID + 登录态）、`social.ts`（关注关系）、`toast.ts`（全局提示）。JWT 前端解码用 `utils/jwt.ts`（base64 解 payload 拿 exp/accountID，**只用于 UI 判断，真鉴权永远在后端**）。

## 复刻建议

- 不必逐像素复刻，**把 9 个页面的 API 调用链对上**即可
- 最低配版本：一个页面 + 表单直接调 6 组 API，能演示全流程就算达标
- 无限滚动：监听 scroll → has_more 时用 next 游标请求下一页（正好检验你的分页协议设计得好不好）
